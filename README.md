# Telegram-бот интернет-магазина

Бот-помощник по покупкам: клиент выбирает язык (RU/UZ), листает категории и
товары, собирает корзину, оформляет заказ (имя, телефон, адрес, комментарий).
Оплата и доставка обсуждаются отдельно с оператором. При новом заказе бот
шлёт уведомление в ваш Telegram-чат.

Каталог товаров хранится в Google Таблице — редактировать его можно без
программиста.

---

## 1. Структура проекта

```
shop-bot/
├── bot.py              # обработчики Telegram, вся логика бота
├── sheets.py            # чтение/запись Google Sheets, кеш каталога
├── locales.py            # тексты интерфейса на русском и узбекском
├── config.py              # загрузка настроек из .env
├── helpers.py               # форматирование цены, счётчик номеров заказов
├── requirements.txt          # зависимости Python
├── .env.example                # шаблон файла с настройками
├── shop-bot.service              # systemd-юнит для автозапуска на сервере
└── README.md
```

## 2. Настройка Google Таблицы

### 2.1. Создайте таблицу

1. Создайте новую Google Таблицу.
2. Переименуйте первый лист в **`Товары`**.
3. В первой строке впишите заголовки колонок ровно в таком виде:

   | Категория | Название | Цена | Остаток | Описание | Фото |
   |---|---|---|---|---|---|

4. Заполните строки товарами. Пример:

   | Категория | Название | Цена | Остаток | Описание | Фото |
   |---|---|---|---|---|---|
   | Керамика | Кружка «Лаванда» | 85000 | 3 | Ручная работа, объём 300мл | https://drive.google.com/uc?id=... |
   | Керамика | Тарелка «Волна» | 120000 | 1 | Авторская работа | https://... |
   | Текстиль | Шарф шёлковый | 250000 | 5 | 100% шёлк, ручная роспись | https://... |

   **Важно:**
   - Пишите название категории **одинаково** для всех товаров этой категории (без опечаток) — иначе бот создаст "дублирующую" категорию.
   - **Цена** и **Остаток** — только числа, без пробелов и текста.
   - **Фото** — прямая публичная ссылка на изображение (см. ниже, как её получить из Google Drive).

### 2.2. Как получить прямую ссылку на фото из Google Drive

1. Загрузите фото на Google Drive.
2. Правый клик на файле → "Открыть доступ" → "Все, у кого есть ссылка".
3. Скопируйте ссылку вида `https://drive.google.com/file/d/ФАЙЛ_ID/view`.
4. Преобразуйте её в прямую ссылку на изображение:
   `https://drive.google.com/uc?id=ФАЙЛ_ID`
   (просто возьмите `ФАЙЛ_ID` из ссылки на шаге 3 и подставьте в этот шаблон).

Проще: используйте любой другой хостинг картинок, который даёт прямую ссылку
на `.jpg`/`.png` (например, Imgur) — тоже подойдёт.

### 2.3. Создайте сервисный аккаунт Google (для доступа бота к таблице)

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте новый проект (или выберите существующий).
3. В меню слева: **APIs & Services → Library** → включите:
   - **Google Sheets API**
4. **APIs & Services → Credentials → Create Credentials → Service Account**.
   - Задайте любое имя, например `shop-bot`.
   - Роль можно не назначать — доступ дадим напрямую на таблицу.
5. Откройте созданный сервисный аккаунт → вкладка **Keys** → **Add Key → Create new key → JSON**.
   Скачается файл — переименуйте его в `credentials.json` и положите в папку проекта.
6. Скопируйте email сервисного аккаунта (выглядит как
   `shop-bot@your-project.iam.gserviceaccount.com`).
7. Откройте вашу Google Таблицу → **Настройки доступа** → добавьте этот email
   с правом **Редактор** (это критично — без прав редактора бот не сможет
   списывать остатки).

### 2.4. Узнайте ID таблицы

Из адресной строки таблицы:
```
https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/edit
                                        └──────────── это ID ────────┘
```

## 3. Создание Telegram-бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram → `/newbot`.
2. Следуйте инструкциям, получите **токен бота**.
3. Чтобы узнать **ADMIN_CHAT_ID** (куда слать уведомления о заказах):
   - Для личного чата с ботом: напишите боту `/start`, затем откройте
     `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` в браузере — там будет `"chat":{"id": ...}`.
   - Для группы: добавьте бота [@userinfobot](https://t.me/userinfobot) в группу — он покажет ID группы (число со знаком минус).

## 4. Установка на сервер (Ubuntu)

### 4.1. Скопируйте проект на сервер

```bash
# на вашем компьютере, из папки с проектом:
scp -r shop-bot/ user@your-server-ip:/opt/
# либо через git clone, если проект в репозитории
```

### 4.2. Установите Python-окружение

```bash
ssh user@your-server-ip
cd /opt/shop-bot

sudo apt update
sudo apt install -y python3-venv python3-pip

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 4.3. Настройте .env и credentials.json

```bash
cp .env.example .env
nano .env       # впишите BOT_TOKEN, ADMIN_CHAT_ID, GOOGLE_SHEET_ID

# загрузите сюда же скачанный ранее credentials.json
# (например, через scp с вашего компьютера):
#   scp credentials.json user@your-server-ip:/opt/shop-bot/
```

### 4.4. Проверьте, что бот запускается вручную

```bash
source venv/bin/activate
python bot.py
```

Напишите боту `/start` в Telegram — если появилось меню выбора языка, всё
настроено верно. Остановите ручной запуск (Ctrl+C) и переходите к автозапуску.

### 4.5. Настройте автозапуск через systemd

1. Отредактируйте `shop-bot.service`:
   - `User=` — замените на реального пользователя на сервере (не root; можно создать отдельного: `sudo useradd -r -s /bin/false botuser`, либо использовать существующего)
   - `WorkingDirectory=` и `ExecStart=` — проверьте, что путь `/opt/shop-bot` совпадает с реальным

2. Установите юнит:

```bash
sudo cp /opt/shop-bot/shop-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable shop-bot
sudo systemctl start shop-bot
```

3. Проверьте статус и логи:

```bash
sudo systemctl status shop-bot
sudo journalctl -u shop-bot -f     # логи в реальном времени
```

Теперь бот будет автоматически перезапускаться при сбое и при перезагрузке
сервера.

## 5. Повседневное использование

- **Добавить товар** — просто добавьте новую строку в Google Таблицу. Бот
  подхватит изменение в течение `CACHE_TTL_SECONDS` (по умолчанию 3 минуты).
- **Товар закончился** — либо поставьте `0` в колонку "Остаток", либо
  дождитесь, пока бот сам обнулит его после заказа.
- **Изменить цену/описание** — отредактируйте соответствующую ячейку.
- **Новый заказ** — придёт сообщением в чат, указанный в `ADMIN_CHAT_ID`,
  с номером заказа, списком товаров, суммой, контактами клиента и его
  Telegram-юзернеймом.
- **Обновить код бота** — залейте новые файлы на сервер и выполните:
  ```bash
  sudo systemctl restart shop-bot
  ```
